## Sumário executivo (10 pontos)

1. **O "agent harness" virou produto gerenciado em todos os grandes provedores em 2026.** Anthropic Managed Agents (beta público desde 08/04/2026, com agendamento cron, vaults, memória, "dreaming"), OpenAI Agents API (beta público em 10/09/2026, sobre o harness do Codex), Microsoft Agent Framework 1.0 + Hosted Agents (GA), LangChain Managed Deep Agents (beta), Vercel AI SDK 7 + Workflows (GA). Você não precisa mais escrever o loop de ferramentas nem a infraestrutura de sessão.
2. **Modelos atuais e preços (por 1M tokens):** Claude Fable 5.1 US$10/50 (cache read US$0,25), Opus 5 US$5/25, Sonnet 5 US$2/10 (preço agora permanente), Haiku 4.5 US$1/5; GPT-6 Astra US$10/50, GPT-5.6 Sol US$4/20, Terra US$2/12, Luna US$0,20/1,20; Gemini 3.8 Flash US$0,75/3,75 (promocional até 31/12/2026), 3.1 Pro US$2/12. Para extração de documentos em volume, o custo por página caiu para frações de centavo.
3. **Leitura de documentos financeiros com LLM multimodal é a abordagem padrão em 2026**, superando OCR clássico em layouts variados, mas com dois cuidados: validação determinística (dígitos verificadores de boleto, EndToEndId de PIX, CNPJ) e fila de revisão humana guiada por confiança/citações. Serviços especializados (Azure Document Intelligence ~US$10/1.000 páginas) continuam úteis para linhas de itens e confiança por campo.
4. **MCP amadureceu como protocolo de integração de agentes**: doado à Agentic AI Foundation (Linux Foundation) em dez/2025, especificação 2026-07-28 tornou o protocolo stateless e apto a load balancers; registro oficial com ~9,6 mil servidores. Supabase tem servidor MCP oficial hospedado com modo somente leitura e escopo por projeto. Não existe MCP oficial da Meta para WhatsApp.
5. **Computer use / browser use saíram do preview**: Anthropic (GA 20/08/2026, com elegibilidade HIPAA para computer use), Claude in Chrome (GA 26/08/2026 em todos os planos pagos, com taxa de sucesso de prompt injection reportada em 0% para Opus 5/Sonnet 5 com salvaguardas), Copilot Studio (GA maio/2026), OpenAI (GPT-6 Astra posicionado como agente de computador). Ainda assim, todos recomendam confirmação humana para ações irreversíveis.
6. **Voz em 2026 é barata e em pt-BR funciona**: GPT-Live-1 (full-duplex, US$0,05/min, 10/09/2026), gpt-realtime-2 (fora de beta desde maio), Gemini Live (GA no Vertex), Deepgram Nova-3 com pt-BR (melhora de ~24% no WER em streaming), transcrição batch a US$0,0045–0,006/min. Escribas clínicos ambientes têm evidência em RCT nos EUA; no Brasil, a Resolução CFM 2.454/2026 (vigente desde 26/08/2026) exige informar o paciente, registrar o uso no prontuário e proíbe a IA de comunicar diagnósticos.
7. **Segurança de agentes tem padrão de referência**: OWASP Top 10 for Agentic Applications 2026 (ASI01–ASI10), princípio de "least agency", credenciais por agente, sandbox com egress deny-by-default. Os provedores oferecem políticas de permissão por ferramenta (`always_ask`/`auto`), eventos auditáveis e orçamentos por execução.
8. **LGPD em 2026 endureceu**: Lei 15.352/2026 transformou a ANPD em agência reguladora; a agenda de fiscalização prioriza dados de saúde; comunicação de incidentes em 3 dias úteis; RIPD recomendado para operações com IA. Nenhum dos três grandes provedores oferece residência de dados no Brasil na API de primeira parte (Anthropic: só "us"/"global"; OpenAI: sem região LatAm; Google: via Vertex/região do projeto, sem confirmação de Gemini em São Paulo).
9. **Zero Data Retention tem letras miúdas**: na Anthropic, Managed Agents, Files API, Batch, code execution e MCP connector **não** são elegíveis a ZDR; Fable 5.1 exige retenção de 30 dias salvo autorização expressa. Na OpenAI, a Agents API é "US-only e sem ZDR" no beta. Para PHI, a Anthropic oferece BAA pela Console com tabela de recursos elegíveis (PDF inline, computer use, memory tool, structured outputs, prompt caching: sim).
10. **Casos reais mostram ganhos concretos, sempre com humano no circuito**: 88% de faturas "touchless" em 120 dias (Peakflo/Haisia), redução de no-show de 41% em grupo de clínicas com voz + WhatsApp, conciliação de 12 meses em uma manhã via Open Finance (Pluggy). As armadilhas repetidas: dados históricos sujos, ausência de métricas, automação total de decisões que exigem julgamento.

### 4.3 Padrão "human in the loop" recomendado em 2026 (síntese)

1. **Extração com esquema estrito** (structured outputs) e **citações** para cada campo (página/trecho de onde veio).
2. **Validações determinísticas** antes de qualquer gravação: DV de linha digitável, formato E2E, mod-11 de CNPJ/CPF, soma de itens = total, data ≤ hoje.
3. **Pontuação de confiança composta**: confiança do provedor (Azure, quando usado), concordância entre dois modelos baratos (por exemplo Haiku 4.5 e Gemini Flash-Lite) e consistência com o histórico (fornecedor conhecido, valor dentro da faixa). Peakflo usa **85%** como limiar para revisão manual ([Peakflo, 14/04/2026](https://peakflo.co/blog/ai-agents-transforming-accounts-payable)).
4. **Fila de revisão** com "um clique" para aprovar (a Fila do dia do app já tem esse desenho) e amostragem semanal dos aprovados automaticamente.
5. **Nunca gravar movimento financeiro a partir de texto encontrado no documento** (instruções embutidas em PDFs são o vetor ASI01 do OWASP).

## 6. Segurança e governança de agentes

### 6.1 Referência: OWASP Top 10 for Agentic Applications 2026 (publicado 09/12/2025)

[genai.owasp.org](https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-for-2026/), detalhamento em [Cycode](https://cycode.com/blog/owasp-top-10-agentic-applications/): ASI01 Agent Goal Hijack (injeção via conteúdo recuperado), ASI02 Tool Misuse, ASI03 Identity & Privilege Abuse (credenciais compartilhadas e amplas), ASI04 Supply Chain (frameworks, servidores MCP, registries), ASI05 Unexpected Code Execution, ASI06 Memory & Context Poisoning, ASI07 Insecure Inter-Agent Communication, ASI08 Cascading Failures, ASI09 Human-Agent Trust Exploitation (resumos confiantes escondendo o que foi feito), ASI10 Rogue Agents. Mitigações: **least agency** (autonomia conquistada, não padrão), identidade por agente com credenciais curtas e escopadas, AI Bill of Materials, sandbox com egress deny-by-default, autenticação mútua entre agentes, monitoramento comportamental com kill switch. Microsoft publicou mapeamento para Copilot Studio em 30/03/2026 ([Security Blog](https://www.microsoft.com/en-us/security/blog/2026/03/30/addressing-the-owasp-top-10-risks-in-agentic-ai-with-microsoft-copilot-studio/)).

### 6.2 O que os provedores oferecem (verificado nas docs)

- **Prompt injection**: Anthropic reporta 0% de sucesso de ataques no Claude in Chrome com Opus 5/Sonnet 5 e salvaguardas; Routines embrulham texto de disparo como não confiável; Supabase MCP embrulha resultados SQL; OpenAI orienta que "texto na tela não concede permissão"; Managed Agents avisam que memory stores de escrita são alvo de envenenamento (use `read_only`). Padrão de arquitetura: instruções do operador via canal separado (mid-conversation system messages), resultados de ferramentas sempre tratados como dados.
- **Permissões e aprovação humana**: `always_ask`/`auto` (Anthropic), `needsApproval` com HMAC (AI SDK 7), aprovação de tool calls (n8n 2.6), PreToolUse hooks (Agent SDK), confirmações de ação (ADK), tool approval (Agent Framework).
- **Auditoria**: eventos com `evaluated_permission`/`evaluation` e `reason_code`; versões imutáveis de memória com redação; eventos de Workflows como histórico durável (exportar, pois a retenção é 7 dias no Pro); OpenTelemetry (n8n, AI SDK 7, Agent Framework); logs por requisição e orçamentos no AI Gateway; Usage & Cost Admin API da Anthropic; inventário de agentes e Entra Agent ID no Copilot Studio; Activity Feed da Anthropic com 6 anos de retenção para compliance.
- **Custos**: orçamento em dólares por execução (Managed Agents), task budgets em tokens, orçamentos por chave/projeto (AI Gateway), Spend Management (Vercel), créditos com limite diário (Routines).

### 6.4 LGPD e dados de saúde no Brasil (2026)

- **Lei 15.352/2026 (25/02/2026)** transformou a ANPD em Agência Nacional de Proteção de Dados, autarquia especial com poder de polícia ([Medicina S/A, 19/08/2026](https://medicinasa.com.br/lgpd-saude-2026/), [Confidata](https://confidata.com.br/blog/anpd-regulacao-ia-brasil-2026-2027)).

- **Obrigações práticas para clínicas**: mapeamento de dados por fluxo clínico, **RIPD para operações com IA**, plano de resposta a incidentes, contratos com operadores (inclui provedores de IA), atenção ao art. 11, §4º (compartilhamento de dados de saúde). - **Implicação prática**: como nenhum provedor oferece residência no Brasil na API direta, a base legal e a transferência internacional devem constar no RIPD e no contrato (DPA); para dados financeiros da clínica sem PHI, o risco é menor; para prontuário/transcrição, prefira ZDR (Anthropic Messages/PDF inline) ou Vertex com região definida, e evite Fable 5.1 (retenção obrigatória) nesses fluxos.

## 7. Casos reais 2025–2026

Lembretes 24 h e 2 h com confirmação em um toque reduzem no-show em 30–40% em vários relatos ([Neuwark](https://neuwark.com/blog/ai-patient-engagement-reduce-no-shows-2026)); clínica odontológica: 12% → 4% ([Intelligent AI Lab](https://intelligentaiautomationlab.com/blog/case-studies/whatsapp-ai-dental-appointment-reminders-case-study-india/)).
